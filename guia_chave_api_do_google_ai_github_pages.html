Chave da API do Google AI

Siga este guia rápido para gerar uma chave de API no Google AI Studio.

Acesso Rápido
Certifique-se de estar conectado com uma conta Google ativa para acessar a plataforma do Google AI Studio.
1

Acessar a Plataforma

Clique aqui ↗ e faça o login com sua conta Google (ou qualquer outra conta que estiver disponível).

2

Navegar até as Chaves de API

No canto inferior direito, você verá um ícone de chave. Clique nele para abrir o painel de gerenciamento.

3

Criar a Chave de API

  1. Ao carregar a página, clique no botão "Criar chave de API".
  2. Insira qualquer nome para este novo projeto e clique em "Criar projeto".
  3. Dê um nome à chave e, em seguida, clique em "Criar chave". Pronto!
Parabéns! 🎉
Sua chave de API do Google AI foi criada com sucesso!

Agora é só copiar a chave e ser feliz.
